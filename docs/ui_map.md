# UI Map

Arabic mobile-first web interface.

## Start page

Dashboard after login.

## Main sections

- dashboard
- sales
- purchases
- data
- reports

## Role menus

Cashier sees sales and customers only.

Stock Keeper sees purchases, items, and stock only.

Accountant sees customers, suppliers, cashboxes, and finance reports.

Owner sees all sections.

## Rule

Each page must check permission before showing data.
