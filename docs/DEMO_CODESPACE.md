# تجربة حِسبة من GitHub Codespaces (DEMO-002)

أسهل طريقة تجرب بيها من غير ما تكتب أي أمر.

1. افتح صفحة الـ repo على GitHub: `hesba_core`.
2. دوس الزرار الأخضر **Code** ← تبويب **Codespaces** ← **Create codespace on develop**.
3. استنى (أول مرة 3–5 دقايق): هيتسطّب كل حاجة ويشتغل لوحده، وهيفتحلك تبويب جديد فيه حِسبة.
   - لو التبويب ماتفتحش: من تحت افتح **PORTS** ← سطر **Hesba demo (8000)** ← دوس الكرة الأرضية.
4. ادخل بـ **owner** والباسورد **Demo-pass-1**.

## مهم
- كل ما تفتح الـ Codespace تاني بيبدأ ديمو جديد من الأول (اختيار النشاط)، ومحدش يسجّل عليه حاجة حقيقية.
- اللينك ده ليك إنت بس (محتاج تكون داخل على GitHub). عشان تبعت لينك لحد تاني استخدم نسخة Render: `docs/DEMO_ON_RENDER.md`.
- لما تخلّص، اقفل الـ Codespace من <https://github.com/codespaces> عشان مايستهلكش الساعات المجانية.
