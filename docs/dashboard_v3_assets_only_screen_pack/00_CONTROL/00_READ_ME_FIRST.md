# DASHBOARD SCREEN PACK v3 FINAL — READ ME FIRST

This pack replaces v1 and v2. Use this v3 pack only.

Goal:
Provide a GitHub Sub Chat with everything needed to implement the approved dashboard visual direction without guessing or inventing assets.

Important decisions:
- The uploaded desktop and mobile images are locked visual references.
- Tablet is LANDSCAPE only.
- Production backgrounds are clean shells only: page background, empty card containers, safe spaces, borders, and soft shadows.
- Icons, charts, logos, hero artwork, rocket artwork, labels, numbers, buttons, values, and alerts are NOT baked into the production background.
- Every icon and reusable visual is separated into its own PNG file.
- Reference sheets exist only for visual comparison and must not be used directly in implementation.
