# Fixed vs Dynamic Rules

## Fixed / allowed in production background
- White page base.
- Empty rounded dashboard containers.
- Empty KPI card frames.
- Empty alerts / quick actions / analytics / onboarding panels.
- Soft borders and shadows.
- Non-clickable decorative wave or light ornaments only if they do not carry meaning.

## Fixed assets but NOT background
These are stable images but must be separate files placed by code:
- Hesba logo.
- Hero analytics illustration.
- KPI icons.
- Quick action icons.
- Alert icons.
- Chart ornaments.
- Rocket illustration.

## Dynamic / must be real UI in code
- All Arabic and English text.
- User name.
- Date and time.
- Notification counts.
- KPI numbers.
- Currency.
- Percent changes.
- Business health score and ring value.
- Chart data.
- Alert messages and severity text.
- Buttons and clickable action tiles.
- Permission-dependent values.

If a thing can change by language, user, data, permission, or click state, it is not allowed inside the background.
