## قرارات معتمدة — مرجع ثابت

**الباليتة**
```
Teal        #02AEB7      Navy        #092851
Teal deep   #025674      Teal wash   #D7F0F1
أحمر        #EA3736      برتقالي     #FB9F00
أخضر        #16A34A      أزرق        #2459A0
```
المرجع: شاشة الداشبورد، مع تصحيح الـ Navy إلى لون اللوجو الحقيقي.

**الأرقام**
الفاصلة = آلاف. النقطة = عشري. دائمًا. الكميات تُحذف أصفارها الزائدة. الفارغ يظهر `—` لا `0.00`.

**العملة**
عملة واحدة للشركة، يختارها المستخدم ويغيّرها. لا تعاملات متعددة العملات في هذه المرحلة.

**التنقّل**
المبيعات والمشتريات **يبقيان منفصلين** — لكل منهما إدارة وصلاحيات مختلفة.

**الموك أب**
مرجع للشكل والألوان والأيقونات والمسافات. **لا** للتنقّل ولا لأسماء الشاشات ولا للنصوص — فيه أخطاء توليد (`٥025`، أيام أسبوع مكسورة).

**التصميم**
خمسة أنماط شاشات، لا ثلاثون شاشة. التصميم يسبق البناء بخطوة. لا بند بصري يبدأ قبل اعتماد تصميمه.

**الموديولات**
البنية تستوعب كل الأنشطة. العرض يُفتح فقط لما تُنفَّذ موديولاته. غير المنفَّذ يظهر "قريبًا" مقفولًا.

## قواعد العمل

1. Claude Code لا يلتزم أبدًا على `main` أو `develop`.
2. كل مهمة على فرع مستقل من `develop` محدَّث.
3. لا دمج بغير موافقة أحمد الصريحة.
4. لا يُعتمد عمل بناءً على "تم بنجاح" — الدليل مطلوب.
5. Main Control يراجع الفرع من GitHub مباشرة قبل الاعتماد.
6. أصغر خطوة قابلة للتراجع دائمًا.
